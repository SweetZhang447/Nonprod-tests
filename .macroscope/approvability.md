# Approvability rules

- Do not approve any PR that changes more than 10 files. Escalate it for human review instead.
- In your reasoning, always state how many files this PR changes and exactly where that number came from (for example: a file count stated in your instructions, your own count of the files in the diff, a git_diff tool call, or a GitHub API response). If these sources disagree, say so and say which one you relied on.
